## Server-side monitoring sync

The `/api/state/sync`, `/api/monitor/*`, `/api/n8n/evaluate`, and `/api/notifications/checkin` endpoints require a shared sync token before they read or write financial state.

Set `PFRE_SYNC_TOKEN` on the server and in n8n. If the browser app should sync state for scheduled n8n checks, also set `NEXT_PUBLIC_PFRE_SYNC_TOKEN` to the same value in the app deployment. Without these values, server-side monitoring remains disabled instead of exposing the last synced financial profile.
