## Secured n8n monitoring sync

Server-side monitoring endpoints require a shared secret before they will read or
write synced financial state. Add a strong value to your app environment:

```bash
PFRE_SYNC_TOKEN=your-shared-secret
```

Enter the same value in Sentra's notification settings and set `PFRE_SYNC_TOKEN`
in n8n variables. Imported n8n workflows send it as the `x-pfre-sync-token`
header when polling `/api/n8n/evaluate` and `/api/monitor/*`.
